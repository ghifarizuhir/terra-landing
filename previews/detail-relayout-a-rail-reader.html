Incident records pack

07 · Reporting & records

Use when close is “fixed” with no documented statement, war-room chats hold the truth, and leadership cannot tell if it came back.

Overview

Incident records pack standardizes what every incident must produce: the incident report, the PIR, the comms log. Core principle: an incident is not done when resolved — it is done when its records close the loop.

When to use

  • Incident closed as “fixed” with empty report
  • War-room exists but no timestamped comms log
  • When NOT to use: no-fault PRB with lean record

Core Pattern

// Before: truth in DMs
resolve(); // report later (never)
// After: pack is the close
const pack = buildIncidentRecords(inc)
// {report, pir, commsLog}
